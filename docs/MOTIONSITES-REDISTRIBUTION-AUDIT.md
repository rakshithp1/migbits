# MotionSites redistribution review

Reviewed 2026-10-27 for MigBits downloadable-library use. Result: BLOCKED, zero imported. No application or deployment changes.

The [site terms](https://motionsites.ai/terms), updated September 30, 2026, permit using prompts/source in websites and apps, but prohibit redistributing prompt/source content, republishing the library and automated bulk collection. Free access is not a separate redistribution grant.

The MotionSites-branded [Claude skill repository](https://github.com/Motionsites-AI/claude-skill) has a split [LICENSE](https://github.com/Motionsites-AI/claude-skill/blob/faa30d512e3973e58675c72101a7ef42ed37ae83/LICENSE): skill instructions, references and scripts are MIT, while example prompts and media are expressly outside that grant. They are permitted for building websites, including client work, but collection resale/redistribution is prohibited. The repository links to motionsites.ai; a reciprocal link from the site was not independently verified. No tooling was installed.

The pinned, untruncated Git tree contains 40 example prompt files and one supporting index. All 40 are recorded as blocked for collection import in `catalog/motionsites-redistribution-audit.json`; the index is excluded from resource counts. Prompt bodies and media were not downloaded. This does not establish the total free-template count of the live website; that remains unverified. The website template page does not expose a complete item inventory in the retrieved page.

Third-party mirrors advertising MIT were not accepted as proof that MotionSites has authorized redistribution of its underlying prompts, code or media. Changing filenames, copy, colours or branding does not establish that permission.

Required next step: written rights-holder permission expressly covering downloadable template/source/prompt/media redistribution and sale through MigBits, with the scope and notices recorded. Independent original designs and separately verified permissive resources remain alternatives. No claim of exhaustive website coverage or of imported MotionSites templates is made.
