# Third-party notices

## Visual resource gallery

The gallery reuses the reviewed, pinned shadcn/ui, Inspo and UI UX Pro Max source already attributed in this project. Their exact notices remain in source payloads and ZIP downloads. Font-family notices and OFL licenses are preserved separately under public/library/fonts and in each font ZIP. OFL fonts are excluded from the standalone resale filter.

New Migbits templates, illustrations and Figma generator kits are original works under resources/library/LICENSE. Each original ZIP preserves that notice; standalone illustration and kit SVGs embed it in metadata. Figma generator packages contain original source and editable SVGs, not third-party Community .fig files. 21st.dev was studied as a UI navigation reference; its screenshots, branding and submissions are not redistributed by Migbits.

## Removed application effects

React Bits Blur Text and Spotlight Card have been removed from the application and current source tree. The call-to-action now uses original static markup. The removed effects are not distributed in current downloads.

## Integrated source

The 65 modules under components/ui/ derive from shadcn/ui, licensed MIT. Preserve components/ui/LICENSE and ORIGIN.json with redistributed copies. The source pack includes both and records its local modifications. The original Migbits settings block and the rest of this application are not relicensed by the pack.

The class-merging helper and theme integration accompany that pack. Installed runtime dependencies retain their own notices; copies of the dependency notices are included under licenses/ in the download. Lucide contains ISC and applicable Feather-derived MIT notices.

## Linked community projects

The collection is documented in docs/OPEN-SOURCE-COLLECTION.md and catalog/community/verified.json. Recorded repository licenses and their hashes are stored under docs/licenses/. Directory entries are links and original descriptions, not copies of those complete libraries. Check the linked version and notices before importing additional source.

## Motion Primitives collection

The six core files under components/motion/ derive from Motion Primitives at the commit recorded in ORIGIN.json and retain its MIT notice. Local policy/type/interaction changes are documented in the same record. The original examples and visibility policy accompany those adapted components. The motion ZIP preserves upstream, helper and dependency notices; it does not relicense unrelated Migbits resources.
## Reviewed imported resources (25 October 2026)

The public Source archive is retired. The library includes reviewed Inspo blocks, UI UX Pro Max palettes, 171 Shaders definitions and 29 Magic UI components, with original MIT notices and pinned revisions. Removed Bencho, ThreeUI and other excluded source packages remain outside delivery; older historical inventory descriptions do not authorize redistribution.

Each original source ZIP preserves its notices. Isolated preview adaptations retain complete upstream and bundled dependency notices in the adjacent previews/LICENSES.txt. Magic UI uses the React/Tailwind preview runtime; the Shaders runtime uses pinned TypeGPU and colorjs.io dependencies. These lazy static preview bundles are separate from the main application's dependency graph. Camera, unlicensed remote media and experimental HTML capture demonstrations are not promoted.

See docs/ARCHIVE-PROMOTION.md and catalog/archive-previews/reconciliation.json for all 270 attempts and held-entry reasons. The existing rights-cleanup and curation records remain in effect. Render checks do not certify every browser, GPU or accessibility behavior.
