# Open-source research and integration

Reviewed 23 October 2026. This is a curated, bounded research pass, not an exhaustive scan of the web.

## Delivered

- 37 verified upstream projects across 8 categories, with original summaries and filters for search, category, stack and license.
- 65 shadcn/ui-derived live components plus 3 composition recipes and six Motion Primitives-derived animated components, each in an attributed complete-file source pack with dependencies and SHA-256 checksums.
- Directory entries link upstream. They do not imply that the whole upstream project is installed, audited, supported, or included in the ZIP.

## Review method

Read the official repository and its license at a recorded commit. Store the full notice locally and its SHA-256 digest. Accept a defined set of permissive license identifiers. Unclassified licenses require hash-bound manual review. Keep restricted, unresolved and unavailable projects out of the permissive collection. Paid products, separate assets, trademarks and external projects are not covered by a root repository license.

The Lucide notice was reviewed as ISC plus the MIT notice for Feather-derived icons; SVG.js was reviewed as MIT despite unresolved automatic classification. Those manual decisions apply only when the license-text hash matches.

## Verification boundaries

Directory license checks are not security or accessibility audits. Component interaction and screenshot review need a connected browser. A production build and standalone source-pack bundle are checked separately. No third-party branding, paid thumbnails, or proprietary templates were copied.

Upstream link checks completed for all 37 entries. React Aria uses its current Adobe domain. Phosphor Explore falls back to the official repository because its project website was unreachable from this environment.
