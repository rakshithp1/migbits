# MotionSites publisher sample import

Imported scope: all 40 design prompt files in the publisher's free sample at `Motionsites-AI/claude-skill`, revision `faa30d512e3973e58675c72101a7ef42ed37ae83`. The index and upstream public license are preserved. Each prompt has a SHA-256 and Git blob checksum; snapshot/fetch scripts resume cached items and never execute publisher scripts.

The records live in **Design prompts**, not the complete Templates count. Upstream categories distinguish heroes, landing pages, portfolios, agency briefs and other design specifications. Nineteen prompts have actual code excerpts; most do not contain an entire runnable application. The original prompt and excerpts remain unchanged in `original/`. A separately labelled MigBits build brief namespaces project/component names and requires accessibility, mobile and reduced-motion adaptations. Cosmetic renaming is not represented as new authorship.

One source, AI Workflow Hero, includes a complete React example. The live edition renames the project to MigBits Flow and replaces the memory-heavy captured-frame video strategy with a native looping video controller. It uses isolated React, Lucide and Tailwind builds, local media, system fonts, pause/reduced-motion support and an honest local-action notice. Original source, adaptation source and full dependency notices are separate in the ZIP. The remaining items show labelled design or motion references, not fabricated working applications. Neo Museum's source is available but its reference media could not be fetched with valid TLS.

Forty prompt packages have sealed browser proofs for opaque sandbox rendering, media availability or explicit unavailable status, pause, reduced motion and mobile width. These proofs establish the preview wrapper; they do not certify 40 complete applications or production accessibility. See `catalog/motionsites-preview-validation.json`.

Forty-nine deduplicated reference images/videos are cached, around 332 MB, and loaded only when opening their resource. They are not installed as dependencies or bundled into every gallery page. Source ZIPs remain small; `REFERENCE-ASSETS.json` lists separately served media URLs and hashes. No font binaries are bundled. Font links inside the unchanged upstream brief are references, not a separate font redistribution grant. Three reference requests are held: one exceeds the delivery limit and two failed certificate validation. Certificates were not bypassed. Three entries have no playable reference: Aethera Hero (oversized video), Neo Museum (certificate errors), and Portfolio Cosmic Hero (HLS stream not packaged by this importer). Their original briefs remain available with explicit unavailable labels. Digital Epoch's trailing URL punctuation was normalized before media discovery.

Source license: MotionSites custom distribution terms, not MIT for prompts/media. The publisher skill's MIT grant excludes its example/media collection. Additional distribution authorization is administered separately; private license documents and contract wording are absent from public files and ZIPs. Copyright and upstream public-license notices remain. MigBits-authored preview code has its own MIT notice. Public download access does not imply a general right to resell the upstream prompt/media collection. The public resale filter conservatively excludes these records.

Coverage is explicit in `catalog/motionsites-live-coverage.json`: 48 free-filter cards were observed in Chrome, with only seven matching the pinned sample by title. Forty-one observed card bodies are outside that export and recorded as blocked-source-access. The direct site request returned 403 and the documented MCP connection failed TLS. No private backend keys or authentication bypass were used. This is a complete import of the 40-file publisher sample, **not a claim that every free item currently on the website has been imported**. An authenticated official export is needed to reconcile the remainder.

Repeatable flow: `python scripts/snapshot-motionsites.py` → `python scripts/fetch-motionsites-media.py` → `npx tsx scripts/build-motionsites.ts` → serve public/ on port 3212 → `node scripts/validate-motionsites.mjs` → `npm run build:catalog`. Normal builds use the pinned source and cached public assets offline, verify their hashes and reject changed sealed artifacts. They do not contact MotionSites or execute its install scripts.
